Troubleshooting Guide

Solutions to common issues and problems

Need More Help?

If you don't find your issue here, check the full troubleshooting guide on GitHub or ask in the discussion forum.

Common Issues

Installation & Environment

Python Version Issues

Problem: Getting errors about Python version compatibility

Solution: Ensure you're using Python 3.10 or higher. Check your version with:

python --version

If you need to install a newer version, visit python.org

Package Installation Failures

Problem: pip install fails or packages don't install correctly

Solution: Try upgrading pip first:

pip install --upgrade pip
pip install -r requirements.txt

If specific packages fail, try installing them individually or use conda instead.

GPU & Hardware

CUDA Not Detected

Problem: PyTorch doesn't detect your GPU

Solution: Check if CUDA is available:

import torch
print(torch.cuda.is_available())
print(torch.version.cuda)

If False, reinstall PyTorch with CUDA support from pytorch.org

Out of Memory Errors

Problem: Getting CUDA out of memory or similar errors

Solution: Try these approaches:

  • Reduce batch size in training scripts
  • Use gradient checkpointing
  • Clear CUDA cache: torch.cuda.empty_cache()
  • Use CPU mode for smaller experiments

Jupyter Notebooks

Kernel Crashes or Restarts

Problem: Jupyter kernel keeps crashing

Solution:

  • Check if you're running out of memory
  • Restart the kernel and clear all outputs
  • Make sure all dependencies are correctly installed
  • Try running in a fresh environment

Notebook Not Loading

Problem: Jupyter notebook files won't open

Solution: Ensure JupyterLab is installed:

pip install jupyterlab
jupyter lab

Then navigate to the notebook in the file browser.

Code & Training

Import Errors

Problem: Can't import reasoning_from_scratch modules

Solution: Make sure you're running from the repository root or install the package:

pip install -e .

This installs the package in editable mode.

Slow Training or Inference

Problem: Code runs very slowly

Solution:

  • Ensure you're using GPU if available
  • Use the optimized versions in bonus folders
  • Enable torch.compile() for faster inference
  • Check CPU usage - you might need more powerful hardware for some chapters

Model & Evaluation

Model Download Issues

Problem: Can't download model weights

Solution:

  • Check your internet connection
  • Make sure you have enough disk space
  • Try downloading manually from HuggingFace
  • Use the checkpoint download scripts in chapter bonus folders

Unexpected Results

Problem: Getting different results than shown in book

Solution:

  • Random seeds may cause slight variations
  • Check your model configuration matches the book
  • Verify you're using the correct dataset
  • Compare with the official solution notebooks

Platform-Specific Issues

Windows

For torch.compile() issues on Windows, see the special guide

macOS

For Apple Silicon (M1/M2/M3), use MPS backend. Check if available with torch.backends.mps.is_available()

Linux

Most issues are CUDA-related. Ensure your CUDA drivers match your PyTorch version
