Chapter Overview

In this chapter, you'll learn the fundamentals of text generation with large language models (LLMs). We'll work with a pre-trained Qwen3 model to understand how LLMs generate text token by token.

Learning Objectives
  • Understand the tokenization process and how text is converted to numerical representations
  • Learn about different decoding strategies (greedy, temperature sampling, top-k, top-p)
  • Implement text generation from scratch using PyTorch
  • Set up and configure your development environment
  • Work with pre-trained model weights and configurations

Code Example

Here's a preview of the text generation function you'll implement:

import torch

def generate_text(model, tokenizer, prompt, max_tokens=100, temperature=1.0):
    """
    Generate text using a pre-trained language model.

    Args:
        model: The pre-trained LLM
        tokenizer: Tokenizer for encoding/decoding text
        prompt: Input text to continue from
        max_tokens: Maximum number of tokens to generate
        temperature: Sampling temperature (higher = more random)

    Returns:
        Generated text as a string
    """
    # Encode the prompt
    input_ids = tokenizer.encode(prompt, return_tensors='pt')

    # Generate tokens one by one
    for _ in range(max_tokens):
        # Get model predictions
        with torch.no_grad():
            outputs = model(input_ids)
            logits = outputs.logits[:, -1, :]

        # Apply temperature and sample
        logits = logits / temperature
        probs = torch.softmax(logits, dim=-1)
        next_token = torch.multinomial(probs, num_samples=1)

        # Append to sequence
        input_ids = torch.cat([input_ids, next_token], dim=-1)

        # Check for end of sequence
        if next_token.item() == tokenizer.eos_token_id:
            break

    # Decode and return
    return tokenizer.decode(input_ids[0])
