Getting Started

1

Clone the Repository

git clone --depth 1 https://github.com/rasbt/reasoning-from-scratch.git
cd reasoning-from-scratch
2

Install Dependencies

pip install -r requirements.txt

See detailed setup instructions for Python and GPU configuration

3

Start Learning

jupyter lab

Navigate to ch02/01_main-chapter-code/ch02_main.ipynb to begin
